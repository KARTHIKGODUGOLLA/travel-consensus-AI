# Security

Use local-only serving for development. Public hosting needs separate access,
privacy, and deployment design. Do not enter real traveller health information,
credentials, or confidential details into demo prompts or fixtures.

Keep API keys out of source and screenshots. Report non-sensitive defects with
synthetic reproductions. For a credential exposure, revoke the key at its
provider and coordinate removal from repository history; a later source edit
alone does not remove an older committed value.
